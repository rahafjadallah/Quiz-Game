# 🎯 Quiz Game

An interactive quiz game built using HTML5, CSS3, and JavaScript. This project allows users to test their general knowledge through multiple-choice questions, track their scores, and receive feedback based on their performance.

## ✨ Features

- Interactive start screen.
- Multiple-choice general knowledge questions.
- Dynamic question display.
- Instant feedback for correct and incorrect answers.
- Score tracking.
- Progress bar to track quiz progress.
- Results screen with personalized feedback based on score.
- Restart quiz functionality.
- Responsive design for different screen sizes.
- Dynamic answer buttons created using JavaScript.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- DOM Manipulation
- Event Listeners
- Arrays & Objects
- Array Methods (`forEach`, `Array.from`)
- `setTimeout()`
- `classList`
- `dataset`

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
4. Click **Start Quiz** and enjoy playing!
